Формат и алиасы колонок

Регистр заголовков не важен. Если несколько колонок из одного списка алиасов — берётся та, чьё имя раньше в списке алиасов.
сумма: сумма, прирост, прирос, рост, итог, sum, amount
Показатель (выбирается переключателем):
· ТН: тн, tn, табельный, таб.ном, табельный номер, emp_id
· КПК: кпк, kpk, клиентский, клиентский пк
· ИНН: инн, inn, tax_id, taxpayer
ТБ: тб, tb, тербанк · ГОСБ: госб, gosb · кластер: кластер, cluster
Обязательны: выбранный показатель + сумма. Остальные колонки опциональны.
Кодировка: UTF-8, windows-1251 и др. определяются автоматически.

3. Параметры победителей
Тип конкурса

Награду получает каждый, кто достиг критерия по сумме (сделал ≥ порога). Задайте число наград и порог для каждой отдельно (например 1, 2, 3, 10).

Турнир: для каждой награды — достоинство (золото / серебро / бронза), круг отбора, направление «лучше» (больше или меньше), и сколько лучших берут (топ N или %). Если несколько наград с одним кругом (например все «страна»), они идут каскадом по достоинству: топ‑2 золото и топ‑5 серебро → первые 2 получают золото, следующие 5 — серебро (уже награждённые на этом круге не пересекаются).

Критерии участия Победителей ищем только среди прошедших фильтр

Пример: основной > 0 — только с положительной суммой; второстепенный «балл» ≥ 85 — только при наличии такой колонки в файле (иначе второстепенный не режет выборку).
