# Аналитика sum-distribution: метрики, графики, таблицы

Документ описывает **реализованный** блок вкладки «Статистика и анализ»  
(адаптация ТЗ `Docs/tz_metrics_charts.md` под поля страницы).

Версия: **2.4.23**

---

## Соответствие ТЗ → страница

| ТЗ | В sum-distribution |
|----|-------------------|
| `growth_sum` | `amount` (сумма / прирост по ТН) |
| `tb_id` | `tb` |
| `gosb_id` | `gosb` |
| `cluster_id` | `cluster` |
| `tab_num` | `tn` (табельный; данные уже агрегированы SUM по ТН) |

Агрегации: вся выборка (через интервалы) и разрезы **ТБ / ГОСБ / кластер / ТН**.

Расчёт выполняется **только** на открытой вкладке «Статистика и анализ»  
(на «Один период» / «Сравнение» тяжёлая аналитика не считается).

## Панель управления

| Контрол | Назначение |
|---------|------------|
| **Разрез** | ТБ / ГОСБ / кластер / ТН — база для рейтингов и таблиц B, F, G, J, L |
| **Метрика** | N, Σ, средняя, медиана, доля >0, score — ось ранжирования |
| **Режим лучших** | Top-N / Top-X% / «шишки» |
| **N / % / порог** | 5 / 10 / 20 / 50 — для Top-N это N; для Top-% — процент; для шишек — порог |
| **Тип шишек** | процентиль / z-score / abs (млрд средней) |

Подсказка под контролами (`analysisRankHint`) поясняет, сколько объектов отобрано и по какой метрике.

Веса score и «млрд» для abs — в `#app-config`:

```json
"analysisScoreWeights": { "avg": 0.5, "median": 0.3, "sharePos": 0.2 },
"analysisBillion": 1000000000
```

## Метрики по группе (категории разреза)

Для каждой категории разреза считаются:

| Метрика | Смысл |
|---------|--------|
| **N** (`count`) | Число ТН в категории |
| **Σ** (`sum`) | Сумма `amount` |
| **Avg** (`avg`) | `Σ / N` |
| **Median** | Медиана `amount` |
| **Std** | Выборочное СКО (`N−1`) |
| **Min / Max** | Минимум / максимум |
| **Q1 / Q3** | 1-й и 3-й квартили |
| **IQR** | `Q3 − Q1` |
| **count_pos / neg / zero** | Число ТН с `amount > 0` / `< 0` / `= 0` |
| **share_pos / neg / zero** | Доли от N |
| **Score** | Композит: `0.5·Z_avg + 0.3·Z_med + 0.2·Z_sharePos` (Z по всем объектам уровня; при `σ=0` → Z=0) |

---

## Режимы отбора «лучших»

1. **Top-N** — первые N после сортировки по выбранной метрике (убывание).
2. **Top-X%** — `N = ceil(M · percent / 100)`, далее как Top-N.
3. **Шишки (outliers)**  
   - *процентиль*: объекты с метрикой ≥ T-го процентиля (порог = T, напр. 90);  
   - *z-score*: `Z ≥ threshold`;  
   - *abs*: `avg ≥ threshold · analysisBillion` (threshold в млрд).  
   Отобранные сортируются по выбранной метрике; присваивается `rank`.

## Как читать (кратко)

- **CDF + интервалы** — подбор границ по целевым долям ТН.  
- **IQR / boxplot / std** — неоднородность внутри категории.  
- **share_pos и score** — качество прироста, а не только объём Σ.  
- **Heatmap** — где ГОСБ сильны/слабы в разных ТБ по средней.  
- **Шишки** — выбросы вверх по avg/score без жёсткого Top-N.

Исходное ТЗ с формулами: [`tz_metrics_charts.md`](tz_metrics_charts.md).
