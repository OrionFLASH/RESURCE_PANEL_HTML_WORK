# Критерии конкурса (`contest-criteria.html`)

Инструмент настройки конкурса по CSV: мультислоты файлов, интервалы/график, победители, устойчивость.

## Файлы

| Путь | Назначение |
|------|------------|
| `contest-criteria.html` | Разметка |
| `css/contest-criteria.css` | Стили Liquid Glass |
| `src/contest_criteria/config.js` | `window.CONTEST_CRITERIA_CONFIG` |
| `src/contest_criteria/app.js` | Слоты, график, победители, UI |
| `src/contest_interest.js` | Diversity / Interest Score / «Предложи лучше» |
| `src/csv_encoding.js` | Автодетект кодировок CSV (UTF-8, windows-1251, …) |
| `ROADMAP_CONTEST.md` | Roadmap |

Открывайте `contest-criteria.html` из корня проекта (относительные пути к `css/` и `src/`).

## Мультислоты

| Режим | Слоты | Подписи |
|-------|-------|---------|
| Месяцы | 12 | янв…дек |
| Кварталы | 4 | кв 1…кв 4 |
| Прошлый / Текущий | 2 | Прошлый, Текущий |
| Свои N | 1…12 | Файл 1… |

Активный слот кормит график и фильтры. **«Применить настройки ко всем»** копирует фильтры и границы.

## Загрузка CSV

- Обязательны: выбранный **показатель** (ТН / КПК / ИНН) + **сумма**.
- Опционально: ТБ, ГОСБ, кластер и любые другие числовые колонки (для критериев участия).
- Кодировка определяется автоматически (`src/csv_encoding.js`).
- Статус загрузки (успех / ошибка) показывается под слотами.

## Критерии участия

Перед отбором победителей:

1. **Основной показатель** — сравнение с суммой после агрегации (например `> 0`).
2. **Второстепенный** — другая колонка файла (имя + сравнение + порог). Если колонки в файле нет — второстепенный фильтр **не применяется**.

Победителей ищем только среди прошедших фильтр участников.

## Победители

- **Индивидуальная награда** — порог по сумме (≥).
- **Турнир** — достоинство (золото / серебро / бронза), круг (страна / ТБ / ГОСБ / кластер / группа), топ N или %.
- На одном круге награды идут **каскадом** по достоинству: топ‑2 золото + топ‑5 серебро → 2 золота, затем следующие 5 серебро (без пересечений).

Расчёт — **по каждому загруженному слоту отдельно**; критерии общие.

## Устойчивость

Interest Score, повторники, покрытие оргструктуры, инфографики; **«Предложи лучше»** — альтернативные правила.
