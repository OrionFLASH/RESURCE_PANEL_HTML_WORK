# Ресурсная панель v8 «Лаунчер»

Локальная панель рабочих ссылок команды: поиск, избранное, встречи, указатель разделов, левая панель групп, проверка доступности. Работает из `file://`, без сервера, CDN и веб-шрифтов.

## Как открыть

- Двойной клик по `panel-v8/index.html` (любой браузер), или
- `panel-v8/open-panel.sh` (macOS, Google Chrome): закрывает ранее открытые окна панели и открывает два — полное и узкое (мобильная ширина).

Если рядом нет `links.js` или в нём ошибка, страница покажет сообщение с причиной (для ошибки — номер ссылки и поле).

## Файлы

```
panel-v8/
  index.html      каркас; подключает panel.css → links.js → panel.js
  panel.css       токены v8 (тёмная и светлая «Туман»), цвета стендов/сегментов, стили
  panel.js        вся логика; чистые функции в window.RP.core
  links.js        ДАННЫЕ: window.RP_LINKS (правится вручную или через редактор)
  open-panel.sh   запуск двух окон в Chrome
  admin/          скрипты администрирования (см. admin/README.md)
  tests/          автотесты
  docs/           спецификация, план, скриншоты (docs/shots/)
  mockups/        эталонный макет E и скриншоты (страницей не используется)
```

## Как править links.js

Файл — `window.RP_LINKS` с полями `version`, `sections`, `favorites`, `settings`, `links`, `adminScripts`. Раздел: `{ id, name, icon }`, порядок в массиве = порядок на странице. Ссылка — по одной на строку:

| Поле | Значение | Обязательно |
|---|---|---|
| `id` | уникальный идентификатор | да |
| `section` | `id` раздела из `sections` | да |
| `title` | название | да |
| `url` | адрес http/https | да, если нет `tool` |
| `env` | стенд: `PROM` / `PSI` / `IFT` | нет |
| `seg` | сегмент сети: `ALPHA` / `SIGMA` | нет |
| `copy` | код, копируется в буфер при клике | нет |
| `icon` | имя иконки; иначе иконка раздела | нет |
| `note` | комментарий в подсказке | нет |
| `fav` | `true` — закреплена в «Избранном» | нет |
| `favHide` | `false` — показывать и в разделе, пока она в «Избранном» (по умолчанию скрыта) | нет |
| `meet` | `true` — встреча Jazz, попадает в полосу «Встречи» | нет |
| `meetHide` | `false` — показывать встречу и в разделе (по умолчанию скрыта) | нет |
| `tool` | `decoder` / `role` — встроенный инструмент вместо URL | нет |
| `check` | `false` — не проверять доступность | нет |

`favorites` — порядок закреплённых ссылок (`id` ссылок с `fav: true`). `settings.favAuto` (по умолчанию `true`) — добирать свободные места «Избранного» самыми частыми по кликам. `adminScripts` — реестр скриптов администрирования.

«Избранное»: сначала закреплённые по порядку `favorites`, затем (если `favAuto`) — самые частые по кликам; мест — сколько плиток помещается в строку (не меньше 4). Показанные закреплённые и встречи скрыты из своих разделов (если не задано `favHide: false` / `meetHide: false`); раздел, ставший пустым, не показывается. При поиске закреплённые ссылки снова видны в разделах. Встреча в «Избранное» не попадает. Порядок встреч — порядок ссылок `meet` в файле.

Доработка 2 (issue #13–#26):
- Добранные по кликам ссылки тоже скрыты из своих разделов, как закреплённые.
- «Избранное» учитывает доступность: пока идёт первая проверка — показаны все кандидаты; после каждой завершённой проверки (в том числе по «Проверить» и фоновой) недоступные уходят в свои разделы, а место занимает следующая закреплённая, затем следующая по кликам доступная (ссылки без кликов не добираются). Снова доступные возвращаются. Статус «локально» считается доступным. Если не осталось ни одной карточки — уведомление «Ни одна карточка не доступна».
- Число открытий (`rp_clicks`) — мелкой цифрой у края плитки, строки раздела, встречи и инструмента; без открытий не показывается. Цифра растёт сразу, порядок «Избранного» — со следующего открытия страницы.
- Фильтры «Стенд» и «Сегмент»: либо «Все», либо несколько значений; отметка всех значений или снятие последнего возвращает «Все». Не запоминаются.
- В разделах доступность показана цветом иконки строки (зелёный — доступно, красный — нет, бледно-жёлтый с еле заметной пульсацией — проверяется), у доступных — тонкая пунктирная рамка; кружок остался в «Избранном», встречах и у инструментов.
- Панель групп при каждой загрузке узкая (на экранах от 767 px); ручное переключение действует до перезагрузки.
- Выбор иконки в администрировании: блок «Часто используемые» (иконки, уже назначенные ссылкам и разделам, по числу применений) и свёрнутые тематические блоки; служебные иконки интерфейса в выбор не попадают, но уже назначенные продолжают отображаться.

Старый формат с `favoriteSeed` по-прежнему читается: при загрузке он превращается в `favorites` (без встреч и инструментов), а «Скачать links.js» пишет уже новый формат.

## Редактор ссылок и выгрузка

Замок в шапке открывает боковую панель «Администрирование», вкладка «Ссылки»: поиск и фильтр по разделу, добавление, изменение, удаление и перемещение ссылок, правка разделов (имя, иконка, порядок); переключатели ★ (избранное) и камера (встреча) у каждой строки, в форме — «Скрыть из раздела»; блоки «Избранное» (порядок, «Добирать по частоте кликов», предупреждение о не поместившихся) и «Встречи» (порядок). Правки сразу видны на странице, но живут в памяти до перезагрузки; счётчик показывает число несохранённых изменений, при закрытии вкладки браузер предупредит. Записать файл из `file://` браузер не позволяет, поэтому: «Скачать links.js» → замените файл `links.js` рядом с `index.html`. «Отменить изменения» возвращает исходное состояние.

## Скрипты администрирования

Вкладка «Скрипты» загружает скрипты из `admin/<id>.js` и копирует их текст для вставки в консоль (F12) на нужной странице. Формат файла и регистрация в `links.js` — в [admin/README.md](admin/README.md). Сейчас скриптов нет.

## Проверка доступности

Для каждой ссылки (кроме `tool` и `check: false`) делается `fetch(url, {mode: "no-cors"})`: ответ — «доступно», ошибка или таймаут 6 с — «недоступно». Не более 6 запросов одновременно. Запуск: при открытии, каждые 120 с и по кнопке «Проверить». Фоновая проверка не сбрасывает известные статусы.

Ограничение: проверяется доступность хоста из текущей сети. Вне корпоративной сети (дома, без VPN) внутренние хосты будут «недоступны» — это честный результат, а не ошибка панели.

## Клавиатура и мышь

| Действие | Результат |
|---|---|
| Ctrl/⌘+K или `/` | фокус на поиск |
| ↑ ↓ | выбор в результатах поиска |
| Enter | открыть выбранную (или первую) ссылку |
| Esc | очистить поиск / закрыть окно |
| Клик по ссылке | скопировать код (если есть `copy`) и открыть в новой вкладке |
| Ctrl/⌘+клик | не открывать, скопировать URL |
| Клик по группе слева | прокрутить к разделу |
| Alt+клик по группе | показать только эту группу |

## localStorage

| Ключ | Что хранит |
|---|---|
| `rp_theme` | тема: `dark` / `light` |
| `rp_clicks` | счётчики кликов для «Избранного» |
| `rp_rail` | больше не читается и не пишется: панель групп при загрузке всегда узкая |
| `rp_groups` | разделы, скрытые «глазом» в панели групп |

Без `localStorage` (запрет браузера) панель работает, просто ничего не запоминает.
