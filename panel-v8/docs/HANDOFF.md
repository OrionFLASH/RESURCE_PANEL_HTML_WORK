## Решения, принятые по ходу (для проверки пользователем)

- R1: e2e копируют панель во временный каталог на каждый тест (Playwright не перехватывает `file://`).
- R2: Ctrl/⌘+клик в тестах — Meta+клик и синтетический `ctrlKey`; Ctrl+клик на macOS обрабатывается и через `contextmenu`.
- R3: редактор реализует §8 полностью, включая правку разделов и `favoriteSeed`.
- R4: команда тестов — `node --test 'panel-v8/tests/*.test.mjs'`.
- R5: избранное без кликов = `favoriteSeed` без встреч/инструментов, первые 9.
- R6: тестовый помощник закрывает браузер и чистит каталог при сбое.
- R7: копирование кода — сначала синхронный `execCommand('copy')`, потом `navigator.clipboard` (иначе копия не успевает до открытия вкладки). Это меняет порядок из спецификации §5.
- R8: поиск групп — по подстроке («дан» находит и «Данные…», и «КАП и загрузка данных»).
- R9: `panel.js` остаётся одним файлом (~1660 строк).
- R10: после «Скачать links.js» отмена изменений откатывает к скачанной версии.
- R11: вместо ручной проверки в Safari — прогон в Playwright WebKit; настоящие Safari, Firefox, СберБраузер не проверены.
