# Ресурсная панель v8 «Лаунчер» — спецификация

Дата: 2026-10-03 · Ветка: `feature/links-panel-v8` · Эталон дизайна: `panel-v8/mockups/variant-E-launcher.html` (+ скриншоты `mockups/shots/E-launcher-v2-*.png`).

## 1. Цель

Заменить `Base version/index.html` (675 КБ, 98 плиток в 8 группах) новой панелью рабочих ссылок в дизайне v8 «Пульт» (SPOD_PROM/web-SPOD-Edit), раскладка «Лаунчер»: поиск во главе, избранное, встречи, указатель разделов, левая панель групп. Режим работы прежний: открывается локально через `file://`, без сервера и сети для самой страницы.

Критерии успеха:
- открытие двойным кликом по `panel-v8/index.html` в СберБраузере, Chrome, Safari, Firefox — без ошибок в консоли;
- на 1440×900 и 1920×1080 всё помещается на один экран без прокрутки; на узких экранах — обычная вертикальная прокрутка, горизонтальной нет нигде;
- ссылки, разделы, коды копирования правятся только в `links.js` (или через редактор с выгрузкой `links.js`);
- проверка доступности, копирование кода, Ctrl/⌘+клик, подсказка — работают как в эталоне.

## 2. Файлы

```
panel-v8/
  index.html      разметка-каркас, подключает файлы ниже (относительные пути)
  panel.css       токены v8 (тёмная по умолчанию + светлая «Туман») + цвета стендов/сегментов + стили
  panel.js        вся логика; чистые функции в window.RP.core (тестируются в Node)
  links.js        ДАННЫЕ: window.RP_LINKS = {...}
  admin/README.md как подключать скрипты администрирования (сейчас скриптов нет)
  tests/          автотесты (Node + Playwright с системным Chrome)
  docs/           эта спецификация и план
  mockups/        эталонный макет E и скриншоты (не используется страницей)
```

Никаких CDN, веб-шрифтов, `fetch` локальных файлов. Иконки — встроенный SVG-спрайт в `panel.js` (набор v8 + chat, video, mail, trophy, ticket, code, star, copy, link, refresh, panel, eye).

Если `links.js` не загрузился или содержит ошибку — страница показывает понятное сообщение («Не найден links.js рядом с index.html» / «Ошибка в links.js: …, ссылка №N, поле …») вместо пустого экрана.

## 3. Формат `links.js`

```js
window.RP_LINKS = {
  version: 1,
  sections: [ { id: "heroes", name: "Герои продаж", icon: "trophy" }, ... ],   // порядок = порядок вывода
  favoriteSeed: ["h-prom-a", "kap-psi", ...],   // стартовое «Избранное», пока нет кликов
  links: [
    { id: "h-psi-a", section: "heroes", title: "Герои продаж",
      url: "https://iam-enigma-psi.omega.sbrf.ru/salesheroes",
      env: "PSI",          // PROM | PSI | IFT | (нет) — стенд
      seg: "ALPHA",        // ALPHA | SIGMA | (нет) — сегмент сети
      copy: "92863949",    // необязательно: код в буфер при клике
      icon: "trophy",      // необязательно: иначе иконка раздела
      note: "текст",       // необязательно: комментарий в подсказке
      meet: true,          // необязательно: встреча Jazz → полоса «Встречи»
      tool: "decoder",     // необязательно: decoder | role — встроенный инструмент вместо URL
      check: false         // необязательно: не проверять доступность
    }
  ],
  adminScripts: []         // реестр будущих скриптов (раздел 8), сейчас пуст
};
```

Валидация при загрузке (`RP.core.validate`): уникальные `id`; `section` существует; есть `url` (http/https) или `tool`; `env`/`seg` из допустимых значений; `favoriteSeed` ссылается на существующие id. Ошибки — в консоль и плашкой в админке; некритичные (неизвестная иконка) не мешают показу.

Стартовые данные — 92 ссылки + 2 инструмента из `mockups/_shared/data.js` (перекомпонованы в 11 разделов: Коммуникации, Герои продаж, КАП и загрузка данных, СУП и релизы, Доступы/HR/аудит, Сервис и заявки, Данные и аналитика, Документация, Задачи и команда, Репозитории, Инструменты), поля переименованы в читаемые (`s→section, t→title, u→url`).

## 4. Экран

Как в эталоне E (v2):
- **Шапка**: кнопка панели групп · знак + «Ресурсная панель» (подзаголовок: N ссылок · M разделов) · сводка доступности (● доступно · ● недоступно · ○ проверяется) · «Проверить» с прогрессом · тема · замок.
- **Поиск** (большой, по центру; при нехватке высоты переезжает в шапку): живой фильтр по названию, домену, разделу, тегам, комментарию; подсветка совпадения; Ctrl/⌘+K — фокус; Enter — открыть первую; ↑↓ — выбор; Esc — очистить.
- **Фильтры-чипы**: Стенд (Все/PROM/ПСИ/ИФТ), Сегмент (Все/Alpha/Sigma). Не запоминаются между открытиями.
- **Избранное**: до 9 ссылок по частоте кликов (`localStorage rp_clicks`), пока кликов нет — `favoriteSeed`; встречи в избранное не попадают; пересчёт порядка — при следующем открытии, чтобы иконки не прыгали.
- **Встречи**: полоса чипов из ссылок с `meet: true`.
- **Указатель**: разделы в N колонках, балансировка по числу строк; строка = иконка · название (многоточие) · значок копирования (если `copy`) · тег стенда · тег сегмента · точка статуса. Подбор плотности: кегль 15 → 14.5 → 14 → (запасной 13), затем число колонок, затем высота строки.
- **Левая панель групп**: состояния развёрнута (248px) / узкая (60px, раскрытие поверх по задержке наведения) / скрыта — `rp_rail`; поиск групп; клик — прокрутка и подсветка раздела; «глаз» — скрыть/показать раздел (`rp_groups`); Alt+клик — только эта группа; «Показать все · скрыто N». <767px — выезжающая шторка.
- **Цвета**: PROM `--env-prom` (красный), ПСИ (янтарный), ИФТ (синий); ALPHA (фиолетовый), SIGMA (бирюзовый); акцент зелёный только для активного/основного.
- **Недоступная ссылка**: гаснет только название; иконка, теги, красная точка — в цвете.
- **Тема**: тёмная по умолчанию, светлая «Туман», `rp_theme`. Все обращения к `localStorage` — в try/catch; без него страница работает (без запоминания).
- Доступность: фокус-кольца, `aria-label`, клавиатурная навигация, контраст ≥ 4.5:1, `prefers-reduced-motion`.

## 5. Поведение ссылки

| Действие | Результат |
|---|---|
| Клик | если есть `copy` — код в буфер + тост «Скопировано: код»; затем открыть URL в новой вкладке; счётчик клика +1 |
| Ctrl/⌘+клик | не открывать; URL в буфер; тост «Ссылка скопирована» (на macOS Ctrl+клик обрабатывается отдельно от контекстного меню) |
| Средняя кнопка | обычное поведение браузера (ссылка — настоящий `<a href target=_blank rel=noopener>`) |
| Наведение (180 мс) | подсказка: название, комментарий, полный URL, домен, путь, параметры списком, «ПСИ · Alpha», статус «Доступен · 240 мс · 12:04» / «Недоступен · таймаут/ошибка сети · 12:04», код копирования, «Клик — открыть · Ctrl+клик — копировать ссылку» |
| Инструмент | открывает окно инструмента (раздел 7) |

Копирование: `navigator.clipboard.writeText`, при недоступности (file://, СберБраузер) — синхронно `document.execCommand('copy')` через скрытый `textarea` в том же обработчике клика. Ошибка копирования — тост «Не удалось скопировать», ссылка всё равно открывается.

## 6. Проверка доступности

`RP.probe` (из `mockups/_shared/probe.js`): `fetch(url, {mode:"no-cors", cache:"no-store", credentials:"omit"})` с кэш-бастером; ответ = доступен, ошибка/таймаут 6 с = недоступен; не более 6 запросов одновременно; новая проверка отменяет запись результатов старой. Запуск: при открытии, каждые 120 с, по кнопке (повторные нажатия во время проверки игнорируются). Фоновая проверка не сбрасывает известные статусы в «проверяется». Пропускаются `tool` и `check: false`. Ограничение: проверяется доступность хоста из текущей сети (вне корп. сети внутренние хосты будут «недоступны» — это честный результат).

## 7. Инструменты (раздел «Инструменты» на главной)

- **Декодер permission**: ввод HEX через запятую → двоичное представление по 8 бит + список включённых битов. Алгоритм 1:1 со старой версией (`RP.core.decodePermission`, покрыт тестами на примерах из старой страницы).
- **Проверка роли (ПСИ)**: поля «Табельный номер» и «Роль» (по умолчанию 673892 и `EFS_NB_SUP_BUSINESS_ADMIN_GAMIFICATION`), «Открыть» активна при заполненных полях, открывает `https://iam-enigma-psi.omega.sbrf.ru/rmkib.support/api/v1/service/auth/explain/html?employee-number=…&role=…`; «По умолчанию».
- Окна: стекло v8, Esc / клик мимо закрывают, фокус удерживается внутри.

## 8. Администрирование (замок в шапке → боковая панель)

Вкладка **«Ссылки»** — редактор:
- таблица ссылок с поиском и фильтром по разделу; форма ссылки: название, URL, раздел, стенд, сегмент, код копирования, иконка (выбор из спрайта), комментарий, встреча, не проверять; добавить / изменить / удалить / переместить вверх-вниз; разделы: добавить, переименовать, сменить иконку, порядок; набор `favoriteSeed`;
- изменения сразу видны на странице (в памяти, до перезагрузки); счётчик «несохранённых изменений N»; предупреждение при закрытии вкладки с несохранёнными изменениями;
- «Скачать links.js» — файл в том же формате (читаемый, по ссылке на строку), инструкция «замените файл рядом с index.html»; «Отменить изменения».
- Записать файл из `file://` браузер не позволяет — поэтому только выгрузка.

Вкладка **«Скрипты»** — площадка (сейчас пусто, пустое состояние с пояснением):
- реестр в `links.js` → `adminScripts: [{ id, title, desc, file: "admin/<id>.js" }]`;
- файл скрипта: `window.RP_ADMIN = window.RP_ADMIN || {}; RP_ADMIN["<id>"] = { title, code: "...текст скрипта для консоли..." };`
- кнопка «Загрузить» вставляет `<script src="admin/<id>.js">` (работает из `file://`), после загрузки кнопка «Копировать» (отдельный клик — чтобы браузер разрешил запись в буфер) копирует `code`, тост с числом символов; ошибка загрузки — сообщение с путём файла;
- `admin/README.md` описывает формат и порядок добавления.

## 9. Исправления относительно старой версии

- копирование кода работает у всех ссылок с `copy` (раньше не работало у 3 плиток без `id` и у «КАП (new)» из-за дубля `id`);
- проверка с таймаутом и ограничением параллельности, настоящий прогресс;
- 554 КБ встроенных скриптов убраны со страницы (будут подключаться файлами).

## 10. Тестирование

- **Node (без браузера)**: `RP.core` — `validate`, `parseUrl` (домен/путь/параметры), `match` (поиск), `rankFavorites`, `decodePermission`, `serializeLinks` (выгрузка → повторная загрузка даёт тот же объект), `balanceColumns`.
- **Playwright + системный Chrome по `file://`**: нет ошибок консоли; вписывание 1440×900 и 1920×1080 (панель развёрнута/узкая/скрыта, обе темы); 390×844 без горизонтальной прокрутки, шторка; поиск и фильтры; клик с кодом → буфер; Ctrl/⌘+клик → URL в буфере; подсказка; панель групп (поиск, скрыть, Alt+клик, Esc); инструменты; редактор: изменить ссылку → видно на странице → выгрузка `links.js` → загрузка выгруженного файла даёт ту же страницу; отсутствующий/битый `links.js` → сообщение.
- Ручная проверка в Safari и Firefox (стекло с `-webkit-backdrop-filter`, копирование, `fetch` из `file://`).
