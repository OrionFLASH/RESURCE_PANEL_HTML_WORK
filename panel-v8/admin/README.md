# Скрипты администрирования

Вкладка «Скрипты» в администрировании (замок в шапке панели) — площадка для служебных скриптов: текст скрипта лежит в отдельном файле рядом с панелью, панель подгружает его по кнопке и копирует в буфер, чтобы вставить в консоль разработчика (F12) на нужной странице.

Сейчас скриптов нет — вкладка показывает пустое состояние.

## 1. Файл скрипта

Положите файл в эту папку: `panel-v8/admin/<id>.js`, где `<id>` — латиница, цифры, `-` и `_`.

```js
window.RP_ADMIN = window.RP_ADMIN || {};
RP_ADMIN["<id>"] = {
  title: "Название скрипта",
  code: "...текст скрипта для консоли..."
};
```

- `code` — обычная строка JavaScript: кавычки и обратные слэши внутри экранируются (`\"`, `\\`), переносы строк — `\n`. Удобнее всего собрать строку через `JSON.stringify(текст)` или записать шаблонной строкой `` `...` `` (тогда экранируются только `` ` `` и `${`).
- Файл подключается обычным `<script src>`: никаких `import`/`export`, только присваивание в `RP_ADMIN`.
- `<id>` в файле должен совпадать с `id` в реестре (см. ниже).

## 2. Запись в реестре

В `links.js` (рядом с `index.html`) добавьте запись в массив `adminScripts`:

```js
"adminScripts": [
  { "id": "<id>", "title": "Название скрипта", "desc": "Что делает, одной строкой", "file": "admin/<id>.js" }
]
```

- `file` — путь относительно `index.html`.
- `desc` — необязательно, показывается под названием.
- Через редактор ссылок реестр не правится — только вручную в `links.js`.

## 3. Как пользоваться

1. Замок в шапке → вкладка «Скрипты».
2. «Загрузить» — панель вставляет `<script src="admin/<id>.js">` и ждёт `RP_ADMIN["<id>"]`.
3. «Копировать» — отдельным кликом (так браузер разрешает запись в буфер) копирует `code`; тост показывает число символов.
4. Вставьте текст в консоль на нужной странице.

Если файл не найден или не задаёт `RP_ADMIN["<id>"]` с полем `code` — под карточкой появится сообщение с путём файла.

Повторная «Загрузка» после перезагрузки страницы берёт свежую версию файла.

## Почему так, а не `fetch`

Панель открывается с диска (`file://`). Браузеры не дают читать соседние файлы через `fetch`, но разрешают подключать их тегом `<script src>` — поэтому скрипт оформлен как JS-файл, который сам кладёт свой текст в `window.RP_ADMIN`.

Из кода панели то же доступно как `RP.admin.loadScript({ id, file })` → `Promise<{ title, code }>`; при ошибке — `Error` с путём файла.
