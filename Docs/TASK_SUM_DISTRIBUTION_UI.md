**Репозиторий:** `RESURCE_PANEL_HTML_WORK`  
**Не трогать:** SPOD_PROM / SPOD_PARCE_LOAD.

## Статус (2.4.19, 2026-08-11)

- Вкладки: **Один период** / **Сравнение** (текущий + прошлый) / **Статистика и анализ**.
- Настройки построения графика над canvas: вид / компоновка / разрез / группы — ровная сетка.
- **Вид** и **Группы** — сегментные переключатели; линия ↔ наложение с перекрытием взаимно блокируются; «Значения» недоступны при разрезе «Вся выборка».
- Кнопки границ с пиктограммами и цветом; компактное поле «Интервалов» (число столбиков).
- Поля мин / группа N / макс под бегунками — равные колонки на ширину шкалы; целые с разделителем разрядов.
- На основном бегунке: номер группы внутри круга; активная граница выделяется; под ней показано текущее значение.
- **Точная настройка**: постоянный блок для выбранной границы (мини-шкала в стиле основной), переключение между границами, синхрон с основной шкалой.
- Фильтры ТБ/ГОСБ/кластер: в сравнении — **union уникальных** из обоих файлов.
- Дерево ТБ/ГОСБ: преимущественно 3 колонки (адаптивно 2/1), длинные названия переносятся по строкам.
- Экспорт внизу с иконками; в сравнении — **оба периода** в одном файле (колонка «Период» / секции).
- В compare overlay/overlap порядок периодов: **прошлый слева, текущий справа**; перекрытие уменьшено.
- Нижний статус «Интервалов… · bars» убран.
- Под заголовком `Распределение сумм` убран текст «Обязательные столбцы…».
- Переключатели `Один период / Сравнение периодов` сделаны sticky (закреплены сверху панели).
- Блоки `1. Данные` и `2. Фильтры` переведены в сворачиваемые секции (`details`) в стиле блока алиасов.
- Состояния по умолчанию: `Данные` — раскрыт, `Фильтры` — свернут.
- Отдельная вкладка аналитики для текущего периода с собственными переключателями: разрез, метрика, размер top/bottom.
- Графики аналитики: интервалы, кумулятивная доля, топ ТБ, топ ГОСБ, топ кластеров, децили, top/bottom по активному разрезу, круговая структура top, диапазон `P10/P50/P90`.
- Таблицы аналитики (расширено до 6): интервальный профиль, концентрация категорий, процентили/коэффициенты, top/bottom по всем разрезам, матрица `ТБ × кластер`, стабильность категорий.
- Аналитика учитывает текущие фильтры и текущие границы интервалов (пересчёт в `rebuild()`).
- Добавлено описание интерпретации: чтение CDF для выбора границ, использование percentiles/IQR для хвостов и разброса, оценка концентрации и стабильности категорий.
- Логика `Авторасчёт границ` в режиме `Только положительные`: колонка отрицательных `[min…0]` вне счётчика K; K — число положительных интервалов на `[0…max]`; выравнивание со **всех** положительных, начиная с первого после 0.
- Кнопки `Равно по ТН` / `Лесенка` / `Равные интервалы` в positive-режиме делят ровно K положительных интервалов по `>0` на `[0…max]`.
- Исправлена синхронизация визуального состояния сегмента `Авторасчёт границ` (подсветка active-кнопки соответствует текущему значению).
- В аналитике ограничено до 2 графиков в ряд и улучшено поведение подписей осей при большом числе категорий.
- Устранён кейс `0..0` после авторазбивки в режиме `Только положительные`: внутренние границы считаются по strictly-positive (`>0`), добавлена защита от дублирующей нулевой границы.
- Авторасчёт границ 2.4.19: поле задаёт интервалы; «все» — K на `[min…max]`; positive — K положительных + колонка отрицательных; граница `0` зафиксирована; выравнивание с первого положительного.
