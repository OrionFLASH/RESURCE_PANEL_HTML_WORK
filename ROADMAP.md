# Roadmap: распределение сумм (ТБ / ГОСБ)

## Цель

Однофайловая HTML-страница для загрузки данных (CSV / вставка таблицы) со столбцами ТБ, ГОСБ, сумма и построения гистограммы распределения сумм по интервалам с фильтрами и разрезами.

## Подзадачи

- [v] Каркас страницы: разметка, стили, встроенный конфиг по умолчанию
- [v] Загрузка данных: CSV-файл и вставка таблицы (CSV/TSV/Excel)
- [v] Парсинг столбцов ТБ / ГОСБ / сумма, нормализация чисел
- [v] Фильтры выбора ТБ и ГОСБ
- [v] Режимы разреза: вся выборка / по ТБ / по ГОСБ / по ТБ+ГОСБ
- [v] Настройка интервалов: число, равная ширина, ручные границы
- [v] Отрисовка гистограммы (Canvas) и таблица частот
- [v] config.json, краткое описание в README, тесты алгоритма интервалов
- [v] Проверка: unit-тесты + HTTP smoke (долгий browser-agent отменён)

## Модули (внутри одного HTML)

- `parseTableText` — разбор CSV/TSV/вставки
- `normalizeAmount` — числа с пробелами и запятыми
- `rebuildFilterOptions` / `filteredRows` — фильтры ТБ/ГОСБ
- `buildBins` — границы интервалов (count / width / custom)
- `computeHistogram` — подсчёт частот по сериям разреза
- `drawHistogram` — отрисовка на canvas
- `renderFrequencyTable` — таблица результатов
