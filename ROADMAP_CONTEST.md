## Параметры победителей

Отдельный блок **«3. Параметры победителей»** (после фильтров). Выбор хранится в `localStorage` (`contestCriteria.winners.v1`) и в памяти страницы.

### Индивидуальная награда

- Число наград настраивается списком карточек.
- У каждой — **критерий** (порог суммы): награду получает каждый, кто **достиг** критерия (`сумма ≥ порог`).
- Опциональная подпись для колонки «Награда» в экспорте.

### Турнир

- У каждой награды: **достоинство** 1–3 (золото / серебро / бронза).
- **Круг отбора:** вся страна / среди ТБ / среди ГОСБ / среди кластера / среди группы (интервал).
- **Лучший:** сделал больше или меньше.
- **Отбор:** лучшие N **или** лучшие P% участников в круге.
- При равенстве результата на границе топа — все с тем же значением тоже получают награду.

### Экспорт

В CSV «исходный + группа» и «показатель + группа» добавлены колонки:

- `Победитель` — `да` / `нет`
- `Награда` — текст награды(й); несколько через `; `

Сводка числа победителей — в блоке параметров (обновляется после пересчёта графика и при любом изменении критериев). Наглядно по уровням:

- для **награды** — вкладки Страна / ТБ / ГОСБ / Кластер / Группа: число участников, число победителей и кто (показатель + сумма);
- для **турнира** — таблица по выбранному кругу (каждый ТБ / ГОСБ / … отдельной строкой).

Кнопка **«Пересчитать»** принудительно обновляет результаты (и график, если данные загружены).
