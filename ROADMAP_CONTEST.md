# Roadmap: критерии конкурса (один файл)

## Цель

Отдельная однофайловая HTML-страница на базе логики распределения сумм, но **только один файл данных** (без сравнения периодов и без вкладки аналитики). Интерфейс графика первой вкладки сохраняется. Дальше страница будет помогать задавать параметры и считать критерии конкурса.

## Подзадачи

- [v] 1. Каркас `contest-criteria.html`: single-логика из `sum-distribution.html`, без вкладок «Сравнение» и «Аналитика»
- [v] 2. Убран второй файл / период B, compare-layout, dual-charts из UI
- [v] 3. В UI «Показатель»; переключатель 3 вариантов поля из `#app-config` (ТН / ID / Логин)
- [v] 4. При смене показателя — перепарсинг уже загруженного файла и пересчёт графика
- [v] 5. Подсказка по алиасам; пункт в основном `ROADMAP.md`
- [ ] 6. Дальнейшие параметры конкурса и расчёты (следующая итерация)
- [ ] 7. Вычистить мёртвый compare/analysis JS (сейчас заглушен null-safe)
